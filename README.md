# BookMind Local

Локальное приложение для Windows 11 (Python + PySide6 + SQLite/FTS5 + Ollama + Qwen): превращает книги и серии в структурированную базу знаний — персонажи, цели, отношения, хронология, мир, загадки, символы, память серии — с цитатой-источником у каждого утверждения. Работает полностью локально: без облаков и платных API (облачные теги моделей заблокированы).

## Возможности
- Импорт TXT / EPUB / FB2 (главы из оглавления, кодировки, дедупликация по SHA-256), ручная правка глав.
- Многоэтапный анализ через Ollama со структурированным JSON: основной (сущности, факты, события) → глубокий (цели и их история, отношения, сюжетные линии, загадки, мотивы) → сводки глав и арок → память серии (противоречия между томами, пересмотр открытых загадок, состояние героев по томам).
- **Каждое утверждение проверяется цитатой**: цитата должна дословно найтись в тексте (нормализация регистра, ё/е, пунктуации). Не подтверждённое сохраняется как `unverified` и не показывается, не попадает в поиск, ответы и экспорт.
- Возобновляемость: результат каждого фрагмента сохраняется атомарно; остановка/сбой/недоступность Ollama не теряют прогресс.
- Вопросы к базе с источниками (`[F1]`/`[C2]`), защита от спойлеров («тома до N»), «недостаточно данных» без вызова модели, если материалов нет.
- Экспорт Markdown / JSON / CSV / HTML, резервные копии (zip + манифест sha256 + проверка целостности БД).
- **Новая книга по мотивам** (вкладка «Новая книга»): из базы знаний строится обезличенный структурный скелет (роли, цели, смены отношений, линии, загадки с подсказками), затем автоматически создаются новая предпосылка, герои и план глав, который следует заданным поворотам, но уходит от оригинала по выбранной «ручке расхождения» (слабое / среднее / сильное). Каждая глава проверяется на имена и события оригинала и при необходимости переделывается; сомнительные главы помечаются, а не скрываются. Результат — «библия» книги (Markdown). Написание самого текста глав — следующий этап, пока не реализован.
- Несколько моделей Qwen, установка и обновление из интерфейса и CLI.

## Установка

**Готовый установщик (Windows 11).** Во вкладке **Releases** репозитория (или в **Actions → Windows-установщик → Artifacts**) лежит `BookMind-Setup-<версия>.exe`: запустите, установка без прав администратора; есть также `BookMind-portable-<версия>.zip`. Данные хранятся в `%LOCALAPPDATA%\BookMind` и не удаляются при деинсталляции.
Установщик собирается автоматически на GitHub (`.github/workflows/release.yml`) при отправке тега `v*` или вручную («Run workflow»). Ollama устанавливается отдельно (https://ollama.com/download): установщик подскажет, если его нет, а само приложение при каждом запуске проверяет Ollama и модель (вкладка **«Система»**), умеет запустить Ollama и предупреждает перед действиями, которым он нужен.

Из исходников: `powershell -ExecutionPolicy Bypass -File scripts\install_windows.ps1` (создаст окружение и ярлык) или вручную:

## Установка из исходников (Windows 11, PowerShell)
Нужны Python 3.12 и [Ollama](https://ollama.com).
```powershell
git clone https://github.com/kclazzy/book-analystest.git W:\BookMindLocal
cd W:\BookMindLocal
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[gui,dev]"
python -m pytest            # без Ollama и сети
python app.py               # запуск окна
```
Ollama должен быть запущен (`ollama serve` или значок в трее). Данные хранятся в `./data` (или `BOOKMIND_DATA_DIR`).

## Папка данных

База анализа, копии книг, экспорт и резервные копии лежат в одной папке (по умолчанию `%LOCALAPPDATA%\\BookMind`). Её можно выбрать самому: «Система» → «Папка данных» → «Изменить папку…». Данные копируются в новое место (база — через безопасное копирование SQLite), старая папка не удаляется. Если выбрать папку, где уже есть данные BookMind, будут использованы они. Изменение вступает в силу после перезапуска. Выбор запоминается в `location.json` в стандартной папке; переменная `BOOKMIND_DATA_DIR` имеет приоритет. Если выбранная папка недоступна (например, отключён диск), приложение вернётся к стандартной.

## Обновление приложения

Установленная версия (из установщика) умеет обновляться изнутри: вкладка «Система» → «Обновление приложения» (кнопка «Проверить»). Проверка при запуске обращается только к `api.github.com` (последний релиз репозитория) и отключается галочкой в том же блоке. Скачивание разрешено только с `github.com`/`githubusercontent.com`, файл проверяется по SHA-256 (из релиза), перед установкой автоматически делается резервная копия `backups/pre-update-<версия>.zip`, затем тихо запускается установщик; данные не затрагиваются. В режиме «из исходников» автоустановка отключена — используйте `git pull`. Обновление появится, когда в Releases выйдет версия новее установленной.

## Модели Qwen
Каталог — `src/bookmind/data/models_catalog.json` (Qwen3.5, Qwen3, Qwen2.5). Наличие тега в реестре Ollama не предполагается: проверяется при установке. Вкладка **«Модели»** в окне или CLI:
```powershell
python app.py status                 # каталог + что установлено
python app.py recommend --vram 12    # что оценочно влезет в видеопамять
python app.py install qwen3.5:9b-q4_K_M
python app.py select qwen3.5:9b-q4_K_M
python app.py check                  # есть ли обновления (registry.ollama.ai; передаются только имена моделей)
python app.py update qwen3.5:9b-q4_K_M
python app.py update-all
python app.py catalog-update my_catalog.json   # добавить новые модели без правки кода
```
Обновление = повторный `pull` (докачиваются изменившиеся слои). При недоступности выбранной модели используются `fallback_models` из `data/settings.json`.

## Как пользоваться
1. **Библиотека → Импорт книги…** (для серии импортируйте тома по порядку в одну серию).
2. Выберите книгу и этапы, нажмите **«Анализировать / продолжить»**. Анализ идёт в фоне, можно остановить и продолжить позже.
3. Вкладки «Персонажи», «Цели», «Отношения», «Хронология», «Загадки», «Противоречия» и др.: строка → внизу подробности и цитаты. Фильтр «Показывать тома до:» скрывает спойлеры во всех вкладках, вопросах и экспорте.
4. «Вопросы» — ответ по источникам; «Отчёты» — экспорт и резервные копии.

## Структура
```
src/bookmind/
  ingestion/  разбор TXT/EPUB/FB2, главы, фрагменты        storage/   SQLite, миграции, репозитории
  llm/        Ollama-клиент, каталог и менеджер моделей     analysis/  конвейер, проверка цитат, сущности, память серии
  services/   библиотека, знания, поиск, вопросы, экспорт, резервные копии, слияние сущностей
  ui/ workers/ окно PySide6 и фоновые потоки                prompts/   шаблоны промптов (можно переопределить в data/prompts)
tests/        207 тестов без сети и без Ollama (подменный сервер и «сценарная» модель)
scripts/benchmark.py   замер импорта/поиска без LLM
bookmind.spec          сборка PyInstaller
```

## Сборка .exe (Windows)
```powershell
pip install pyinstaller
pyinstaller bookmind.spec --noconfirm     # dist\BookMind\BookMind.exe
```
Сборка проверена только на Linux (запускается); на Windows не проверялась.

## Тесты
`python -m pytest` — без Ollama и сети. `python -m pytest -m integration` — проверка с реальным Ollama, если он запущен. GUI-тесты идут в режиме offscreen и пропускаются, если PySide6 не установлен.

## Ограничения
- Проверка на сходство с оригиналом лексическая (по основам слов): ловит копирование и перекраску имён, но не гарантирует обнаружение глубокого пересказа другими словами. Для публикации чужой книги нужна собственная юридическая оценка.
- Качество извлечения определяется моделью; код проверен на эталонном вымышленном романе со **сценарными** ответами модели, а не на реальной Qwen. Реальный прогон на вашем Ollama нужно сделать самостоятельно.
- Анализ 9B-моделью на длинной книге занимает часы (оценка в `scripts/benchmark.py`, не измерение).
- Нет «разъединения» ошибочно слитых сущностей; одноимённые персонажи в одной книге зависят от того, как их назовёт модель.
- Хронология «в порядке событий» — оценка по времени, указанному в тексте, а не точная датировка.
